NOIR BARBER — demo strony wizytówki
====================================

Pliki:
- index.html
- style.css
- script.js

Uruchomienie:
1. Otwórz index.html w przeglądarce.
2. Możesz wrzucić cały folder na GitHub Pages.

Przed pokazaniem klientowi zmień:
- nazwę NOIR BARBER
- adres
- telefon
- godziny
- ceny
- linki social media
- zdjęcia w style.css

Zdjęcia demo pochodzą z Unsplash i wymagają internetu.
